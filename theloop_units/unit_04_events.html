📖 Field Manual: EVENTS

An EVENT block only runs its steps when its trigger actually happens. Three rules to remember:

  1. It doesn't run on a fixed schedule — not a set number of times, and not just because the program started. It waits.
  2. You don't control WHEN it fires — the mission does. You only decide WHAT happens when it does.
  3. It can go anywhere in your program — it isn't a step in your sequence. It's "listening" the whole time the mission runs, no matter where you place it in your program list.
