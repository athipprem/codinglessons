📖 Field Manual: VARIABLES

A VARIABLE like FUEL is a named box that holds a value — and unlike a fixed number typed into your program, that value can change while the mission runs. Three rules to remember:

  1. It changes as things happen — FUEL drops a little on every move, automatically, without you writing a command that says "subtract one" anywhere.
  2. It keeps whatever value it has until something changes it again — it doesn't reset on its own between steps, and it carries the same number forward from move to move.
  3. Other things read it and act on it — not just you. Rover-7's own systems check FUEL after every move and end the run if it runs out, and an IF block can check "Fuel Low" and branch on whatever FUEL currently reads, without your program ever writing that number down.

Worked example — a tank draining across three moves:

FUEL: 6 → Forward → FUEL: 5 → Forward → FUEL: 4 → Forward → FUEL: 3

Nobody typed "3" anywhere in the program — it's being tracked as things happen, one move at a time, and Command Control reads whatever it currently says after every single step.
