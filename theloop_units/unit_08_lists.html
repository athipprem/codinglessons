A LIST fixes that. It's one named track that holds MANY values together, in a fixed order — like Cargo: [1, 2, 3]. It's the same idea as a grocery list: one piece of paper, several items, in order — not a separate sticky note for every single item.

📖 Field Manual: LISTS

A LIST is one named track that holds MANY values together, in a fixed order. Three rules to remember:

  1. 📦 Add Cargo always adds onto the END, and it always adds the next number in order — an empty list's first Add is 1, the second Add is 2, and so on. The new value always becomes the LAST item.
  2. ⏮ Remove 1st Cargo removes the FIRST value, and ⏭ Remove Last Cargo removes the LAST value — every other value shifts to fill the gap, but nothing in the middle can be removed directly.
  3. Command Control checks the EXACT final list — the same values, in the same order — not just how many Adds or Removes you clicked.
