📖 Field Manual: DEBUGGING

Five steps, in this order:

  1. Reproduce: run it and see the problem for yourself.
  2. Watch: use ⏭ Step and find the FIRST moment it stops matching what you expected.
  3. Guess once: which ONE line could cause exactly that?
  4. Change one thing — a number, a direction, a condition, or the order.
  5. Re-test. If nothing changed, your guess was wrong — put it back and guess again.

It's the same loop you use checking a wrong answer in a maths competition: redo it, find the first line where your working stops matching, fix only that line.

Worked example — a small drawn platform. The program is Repeat ×2 [Right] · Up · Up, and the flag is one square further right than Rover-7 reaches:

Rover-7 ends one square LEFT of the flag. Which line decides how far right it goes? Only the Repeat. Guess: the count should be 3. Change only that, re-run — ✅.
