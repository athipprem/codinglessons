📖 Field Manual: CUSTOM BLOCKS

A CUSTOM BLOCK is a named group of steps you build once, that you can then run from anywhere just by calling its name. Three rules to remember:

  1. You define it once — give it a name, fill it with steps. After that, you never need to rebuild it.
  2. Calling it runs its exact recorded steps, in order, every single time — the whole point is that it doesn't change unless you go back and edit the definition itself.
  3. Command Control counts how many times you actually CALL it during the run — not just whether you built one and never used it.
