📖 Field Manual: CUSTOM BLOCKS

  1. Build it once. 🧩 Define Block, give it a name, put moves inside, ✅ Done. A recipe on its own does nothing.
  2. ▶ Call runs the whole recipe right where the call sits. Three calls = the recipe runs three times.
  3. A block's recipe costs ONE program slot, and each call costs ONE. A routine you need in three places is cheaper as a block.
  4. A block can take a NUMBER. Tick "takes a number", set a Repeat inside it to n, and every call picks its own n.

Worked example — one recipe, two sizes:

🧩 STEP (takes a number) = [ Repeat n [Right], Up ]
▶ STEP(3) → Right, Right, Right, Up
▶ STEP(1) → Right, Up

One recipe, two sizes. In Python this is def step(n): — you'll write exactly this on The Core.
